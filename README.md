# Proyecto-Gestion-Software - Control Asistencia ENSMB

## Integrantes
José Alejandro Cano Campos
Diana Lilia Ortiz Vitervo

##Descripción
Sistema Web para el Control y Registro de Asistencia de Eventos Cívicos "Control Asistencia ENSMB".

##Objetivos
Desarrollar e implementar un sistema web para el registro y control de asistencia de eventos cívicos en la Escuela Normal Superior Mixteca Baja, permitiendo una gestión digital precisa, centralizada y eficiente de la información estudiantil mediante una interfaz responsiva. 

##Alcance
Estarán sujetos a control de calidad todos los artefactos del software: especificación de requisitos, modelo relacional (normalización 3FN), código fuente PHP 8.2 con PDO, interfaz de usuario (HTML5/CSS3/JS), base de datos MySQL 8.0, scripts de pruebas y la documentación técnica/manuales. 

Repositorio para el proyecto de Gestión de Proyectos de Software.
